# Paso 11 — cliente móvil de transiciones de jornadas

El flag SYNC_JOURNEY_RPC_V1=true activa las RPC compartidas del repositorio Web (backend/journey_transitions_v1.sql) para cierre y reanudación. No activar sin staging y pruebas. Sin flag continúa finish_mobile_journey de la versión anterior, que también requiere instalación. Reanudación visible a administradores en jornadas incompletas con pendientes. Cierre incompleto confirmado explícitamente por el usuario. Las RPC usan la versión remota leída, y la interfaz recarga tras respuesta; no genera eventos locales duplicados. No cambia la atención existente con CAS, no añade outbox offline de jornadas, corrección coordinada tras reanudación ni pronósticos. La validación de tipos personalizados y la creación móvil de esas jornadas siguen pendientes. CI y pruebas reales de backend pendientes.

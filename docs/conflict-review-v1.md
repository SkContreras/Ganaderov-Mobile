# Paso 8 — revisión de conflictos móvil
Inspección de operación RPC original y explicación del código. Operaciones de resultado desconocido no se pueden descartar por UI/repositorio. Conflictos/rechazos explícitos se archivan (estado archived) conservando cuerpo y UUID, no se reenvían ni se muestran en cola activa. No existe aún interfaz para recuperar archivados. No se cambia el servidor, no se sobrescribe historial, no se generan operaciones nuevas automáticamente. Las entradas legadas conservan descarte previo. No habilitar RPC en producción antes de staging. La comparación de tres vías de fichas/jornadas se prepara en web; Android todavía no tiene edición offline de fichas ni base histórica verificable. La resolución efectiva por campo requiere RPC de edición y revisiones, pendiente. Prueba de archivo añadida; CI pendiente.

# Android v2
Per-account derived keys using HMAC-SHA256 from the installation root. GCM2 is the version marker; migrate gcm1 and plaintext with the same original operation body. Missing root with encrypted data stops opening, never overwrites the queue. Supabase session storage adapter migrates previous SharedPreferences session to secure storage (verify exact legacy key against installed SDK). Worker uses same root and derivation. This is application-layer encryption, not SQLCipher. Root rotation and physical plaintext cleanup still need a separate migration; derived keys share root trust. CI and device validation required.
